# Guide de contribution Superpowers

## Création d’une nouvelle skill

- Utilisez le template SKILL.md
- Remplissez le frontmatter (name, description)
- Ajoutez des exemples d’utilisation
- Vérifiez la validité avec `npm run validate-skills`

## Critères d’acceptation

- Tests unitaires et d’intégration présents
- Documentation claire
- Respect des conventions de nommage

## Checklist de review

- [ ] Frontmatter complet
- [ ] Tests passés
- [ ] Documentation à jour
- [ ] Pas de régression sur les workflows
